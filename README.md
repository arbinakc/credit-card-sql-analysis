# credit-card-sql-analysis
A relational SQL project tracking cardholders, credit cards, and statements.

Overview
-Worked with a relational database using MySQL.
-Explored three related tables.
-Analyzed credit limits, payments, fees, and balances.

Problem Statement
-Managing credit card records can be difficult.
-Financial institutions need to track credit limits and late payments.
-This project uses SQL to analyze credit card data.

Database Tables
-cardholders: Stores customer details.
-cards: Stores credit card information.
-statements: Stores monthly billing details.

Tools and Technologies
-MySQL Workbench
-GitHub

SQL Concepts Used
-Database Creation: CREATE DATABASE, CREATE TABLE
-Filtering: WHERE, BETWEEN, LIKE
-Sorting: ORDER BY, LIMIT
-Aggregate Functions: COUNT(), AVG()
-Grouping: GROUP BY, HAVING
-Conditional Statements: CASE
-Joins: INNER JOIN, LEFT JOIN
-Subqueries: Used to perform additional data analysis.

Key Insights
-Identified cards with high credit limits.
-Analyzed credit card networks.
-Found cardholders without issued cards.
-Examined late payments and fees.
-Analyzed monthly purchases and balances.

Project Outputs
-Customer details
-Top 5 credit limits
-Card network analysis
-Credit limit categories
-Average credit limit
-Late payment analysis
-Monthly statement details

Conclusion
-Practiced SQL using a financial dataset.
-Improved my understanding of related tables.
-Used SQL to analyze credit card information.
